# Pulp Hour 视觉规范

## 1. 视觉命题

- 游戏与受众：面向移动端、单手操作的短篇互动怪谈读者，每局约 4–12 次选择。
- 情绪承诺：像从雨夜地摊抽出一本会把玩家卷进去的廉价犯罪杂志。
- 一句话方向：旧纸、粗墨、网点和不安的高饱和三原色，共同构成一册可玩的 1960 年代纸浆漫画。
- 标志画面：玩家身份像案件照片一样锁在中央方框，电话、百叶窗、探照灯等当前剧情证据围绕其变化。
- 必须具备：强黑色轮廓、旧纸触感、两秒内可读的动作/选择。
- 避免方向：光滑科技玻璃、柔和生活方式摄影、无结构的通用 AI 奇幻画。

## 2. 构图与视角

- 竖屏优先，验收尺寸为 390×844 与 320×568；页面最大宽 640 px。
- 列表、选刊、写作、结局保持单列阅读轴；核心按钮放在拇指可达的下半屏。
- 故事图由媒体服务直接输出 768×512，匹配写作页和阅读器的 4:3 视窗，不依赖裁切。
- 玩家有头像时，中央方形身份框约占生成图高度 68%，四边保留完整边距，剧情现场只作为四周环境边框；玩家不在框外重复出现。
- 平台内构图不为外部访客栏预留高度；外部访客栏只做可用性检查。

## 3. 色彩

- 纸张 `#fbf4dd`、旧纸 `#f4ecd8`、主墨 `#111111`、次级墨 `#4a4338`。
- 归档黄 `#ffd60a`、失败红 `#e63946`、顺从蓝 `#2c6df4`、谎言粉 `#ff6b9d`。
- 生成图以芥末黄、血红、墨黑、陈纸米色为主，蓝/粉只作选项与小面积身份特征，不铺满背景。
- 禁止霓虹渐变、低对比灰字叠图以及同时使用三个以上高饱和大色块。

## 4. 字体

- 标题采用 Bangers / Knewave / Permanent Marker 气质的粗展示字；正文为 Inter / system-ui，中文回退系统黑体。
- 大标题 22–56 px，主要正文 16–17 px / 1.55；选择轴 26 px 大写，说明 12 px。
- 生成图内禁止可读文字、伪字、对白框；所有可读内容由 DOM 排版。

## 5. 形状、材质与光

- 3 px 黑边、硬质矩形、轻微错位投影；圆角只用于必要的触控与状态标签。
- 表面允许旧纸颗粒、半色调网点、粗印刷套色偏移；不使用玻璃拟态和柔光发光卡片。
- 场景灯光来自百叶窗、桌灯、探照灯或街灯的单一硬光源，暗部保留大片黑墨。

## 6. 角色、环境与素材

- 玩家头像是完整视觉身份，不只是脸。生成前置合同保留物种、轮廓、材质、遮挡、服装、颜色、图案和配件。
- 参考图未出现的脸、皮肤、头发、手、臂、腿不得补画；当前动作在身份框外围以道具和环境证据表达。
- 有头像只传 1 个原始公网 HTTPS 引用并使用 `edit`；无头像不传引用并使用 `text`。
- 封面图不能作为匿名玩家身份或生成参考，只在选刊与失败回退时出现。

## 7. UI 与图标

- 功能图标使用统一的自绘硬边 SVG 体系，不使用 Emoji 或文字字符充当按钮图标。
- 触控目标至少 44×44 px；动作按钮用 `onPointerDown`，可滚动杂志架卡片用 `onClick`。
- 默认、按下、加载、失败、成功均保持粗边框和纸张材质；失败态必须提供清晰的重试章。

## 8. 动效与反馈

- 常规按压 80–140 ms，印章弹入 280 ms；等待时用印刷机/网点节奏，不用无限旋转科技加载环。
- 点击音为短促三角波；成败主要通过黄/红印章和排版变化表达。
- `prefers-reduced-motion` 下取消位移、弹跳与平滑滚动，保留颜色和文字状态。

## 9. 参考原则

- 参考 1960 年代美国纸浆犯罪杂志：采用有限色、夸张硬光和粗印刷质感，不复制具体封面、角色或商标。
- 参考案件档案板：把身份与现场证据分层组织，不加入真实警务标识或仿冒公文。

## 10. 反模式

- 禁止把玩家头像只保留脸后换成通用人类身体。
- 禁止让无脸/非人玩家长出人脸或四肢，禁止遗漏标志性补丁、铃铛、面具等配件。
- 禁止把玩家身份复制给 NPC、倒影或道具，也禁止同一画面出现两个玩家副本。
- 禁止以旧封面替代当前剧情生成、以生成成功状态代替像素验收。

## 11. 垂直切片验收

- 入口：杂志架和选刊在 390×844、320×568 均可滚动、可读、可点。
- 玩法：新 panel 先即时显示印刷占位，再进入当前剧情图；选择区不被长文撑出屏幕。
- 高反馈：结局印章、失败重试章和新 panel 到达形成明确状态变化。
- 结局：最终海报、标题、正文、作者和发布/返回按钮无横向溢出。
- 身份：真人参考保留脸、灰西装和蓝绿围巾；无脸测试角色保留完整白罩、双眼孔、蓝色补丁与铜铃，且无新增脸、皮肤或四肢；无头像图只表现当前现场。
